# 설계 알고리즘 — 엑셀 의뢰서 → 기어 제원표 + BOM (첫 단계)

2026-11-24 · 초안 v1.0 · 근거: 사용자 질의응답 20건 (#73) · 작성 Claude

이 문서는 사이트가 **AI 호출 없이** 엑셀 의뢰서 한 장으로 감속기 컨셉 초안(기어 제원표 + 부품 BOM)을 만드는 규칙의 단일 정의다. 코드(`autodesign.js`, 예정)는 이 문서를 그대로 구현하고, 문서에 없는 판단은 하지 않는다.

## 2. 정격 체계 (상용 감속기 카탈로그 방식)

실제 관절 사용 데이터를 얻을 방법이 없으므로(Q7) 상용 유성 감속기 카탈로그의 정격 정의를 따른다(Q8).

| 정격 | 정의 | 계산 방법 | 카탈로그 근거 |
| --- | --- | --- | --- |
| **정격 토크 T_R** | 정격 입력 회전수 n_r에서 정격 수명 L_R 동안 연속 운전 가능한 출력 토크 | 기어: ISO 6336-2/-3 수명 계수(ZNT·YNT)로 L_R 시간의 반복수에서 SH ≥ SHmin, SF ≥ SFmin을 만족하는 최대 토크 · 유성 베어링: ISO 281 L10 ≥ L_R | Nidec 유성 감속기: 공칭 입력 회전수에서 수명 20,000 h / Harmonic Planetary HPGP: 입력 3,000 rpm에서 L10 20,000 h |
| **반복 피크 토크 T_A** | 기동·정지(가감속) 때 반복해서 허용되는 토크 | ISO 6336 정적 강도(낮은 반복수 영역) SH ≥ SHstat, SF ≥ SFstat · 베어링 ISO 76 s0 | Nidec: 기동·정지 시 최대 토크 / Harmonic Drive: Limit for Repeated Peak Torque |
| **순간 최대 토크 T_M** | 충돌·비상정지 때 허용되는 토크 (수명 중 제한 횟수) | ISO 6336 정적 강도 S ≥ 1 · 결합부·핀 정적 · 출력 베어링 s0 | Nidec: 비상정지 토크, 수명 중 1,000회 허용 / Harmonic Drive: Limit for Momentary Peak Torque |

**기본값:** L_R = 20,000 h (유성 감속기 카탈로그 관례). 사용자가 I11을 넣으면 그 값을 쓴다.

### 2-1. 요구 정격 산출 (입력 → 요구 T_R · T_A · T_M)

모터 출력이 감속기에 걸 수 있는 토크를 상한으로 본다. η = 정격 효율 (계산값, 처음에는 0.95 가정 후 반복).

| I6 (T_req 종류) | 요구 T_R | 요구 T_A | 요구 T_M |
| --- | --- | --- | --- |
| 정격 | T_req | max(T_m,max · i · η, T_req) | max(T_A × 1.5, T_m,max · i · η) |
| 반복 피크 | min(T_m,r · i · η, T_req) | T_req | max(T_A × 1.5, T_m,max · i · η) |
| 순간 최대 | min(T_m,r · i · η, T_req / 2) | min(T_m,max · i · η, T_req) | T_req |
| **모름** | T_m,r · i · η | T_m,max · i · η | T_A × 1.5 |

- "모름"은 **모터가 낼 수 있는 토크 전부를 감속기가 받는다**는 보수적 가정이다. 결과에 이 가정을 표시한다.
- 비율 1.5, 1/2는 **가정**이다(카탈로그의 반복 피크 / 순간 최대 비가 대략 1.5~2배인 관례). 실측·KISSsoft 자료가 쌓이면 §8에서 보정한다.
- 출력 회전수 = n_r / i, 최대 = n_max / i.

## 3. 판정 기준

| 대상 | 기준 | 근거 |
| --- | --- | --- |
| 계산 조건 | **ISO 6336 계산 조건** (`loads.basis = 'iso'`, 정밀도 등급 공차 적용) | Q11 |
| 기본 안전율 | 요구 T_R(정격 수명)에서 **SH ≥ 1.0 · SF ≥ 1.4**, 요구 T_A · T_M(정적)에서 SHstat ≥ 1.0 · SFstat ≥ 1.2. 토크에 별도 여유 배수를 곱하지 않는다 | 사용자 결정 2026-11-26 (SF-1) — 이전 'T × 1.3'은 SF 1.4와 겹쳐 굽힘 여유가 1.82배가 되므로 폐지 |
| 수명 | 요구 T_R · n_r에서 예측 수명 ≥ L_R (기어는 위 SH · SF로 판정, 유성 베어링 ISO 281 L10) | SF-1 |
| 결합부 | 링–하우징 · C1–S2 · S1–모터축 · C2–출력 플랜지: 전달 ≥ 1.5 × T_A (기존 판정 유지), 볼트 벌어짐 ≥ 1.5 | VDI 2230 · 기존 2-4/2-5/2-6/2-8 |
| 출력 베어링 | 외력 입력 시 L10 ≥ L_R, s0 ≥ 1.0 (T_M 비율 외력) · 결합 H7/h7 | ISO 281 · ISO 76 · 사용자 기준 F-1 |
| 소형 감속기 | ISO 방법 C 저하중 영역(정격 Fm/b < 100 N/mm)은 **근거 재검토 대상**으로 표시. KISSsoft 보고서로 보정 전까지는 ISO 값 그대로 판정하고 "재검토 대상" 표시 | Q11 · #69 |

## 5. 결정 순서

```
S0  요구 정격 산출 (§2-1) ─ 정격 토크·반복 피크·순간 최대·회전수·수명
S1  단수 · 링 방식 후보: i ≤ 10 → 1단 / 2단 공용 / 2단 분리
S2  2단 감속비 배분: i = i1 · i2 후보 (i1 ≤ i2, 각 3~10), 토크 균형
S3  단별 잇수 열거: 조립 조건 (S+R)/n 정수 · 인접 유성 간섭 · 감속비 오차 ≤ 1 % · 언더컷 없음
S4  외형 예산: 링 외경 ≤ D_max − 2 × 하우징 벽 · 축방향 길이 = 기어 폭 + 캐리어 판 + 출력 베어링 + 커버 ≤ L_max
S5  단별 모듈·치폭: 예산 안에서 각 단이 요구 T_R·T_A·T_M에서 기본 안전율(§3)을 만족하는 최소 모듈 → 남는 축방향 길이는 여유가 작은 단에 배분
S6  핀 · 유성 베어링: 유성 보어 안 최대 핀 지름 (1 mm 단위) · 풀니들 (0.5 mm 단위), ISO 281 · ISO 76
S7  중공: I10 지정 시 그 값 확보, 빈칸이면 S1 썬 보어·림 두께 한계 안 최대 (림 두께 ISO 6336-3 YB 범위)
S8  출력 베어링 · 결합 구조: 외경 안 카탈로그 형번, 결합 카탈로그(J1~J21)의 기본 경우 + 판정 미달 시 다음 경우
S9  시스템 판정 (§3) → 미달이면 §6 수정 규칙 → 다시 S9 (최대 12회)
S10 선택: 전 항목 충족 후보 중 질량 최소 → 동률이면 최소 여유 최대. 충족 후보 없으면 미달 수 최소 + 부족분 보고
```

각 단계의 결정은 "항목 · 값 · 이유 · 근거"로 기록한다 (설계 결정 기록).

## 6. 수정 규칙 (미달 → 조치, 타협 순서 준수)

한 번에 한 조치를 적용하고, 미달 수 또는 연속 부족량이 줄 때만 채택한다. 외형 한계를 넘는 조치는 되돌린다.

| 미달 | 조치 순서 (앞에서부터) | 근거 |
| --- | --- | --- |
| 기어 치면·치근 (정격·피크·순간) | ① 해당 단 치폭 +1 mm (축방향 예산 안) ② 다른 단 치폭을 줄여 이동 ③ 모듈 한 단계 ↑ (S3부터 다시) ④ 감속비 배분 변경 ⑤ (마지막) 정밀도 5급 | ISO 6336-2/-3 |
| 유성 베어링 L10 · s0 | ① 핀 지름 +1 mm (유성 림 한계 안) ② 니들 지름 +0.5 mm ③ 치폭 증가 | ISO 281 · ISO 76 |
| 핀 · 캐리어 | ① 핀 지름 +1 mm ② 캐리어 판 두께 ③ 편단 → 양단 | 보 이론 · 기존 6-x |
| 결합부 (2-4 · 2-5 · 2-6 · 2-8 · 8-3) | 결합 카탈로그의 다음 경우 · 볼트 호칭·개수 단계 ↑ | VDI 2230 · 결합 카탈로그 |
| 출력 베어링 결합 | 보스·안착 치수를 베어링 치수에 맞춤 (자동값만) | ISO 286 · F-1 |
| 축방향 물림률 εβ | 치폭 조정 (εβ ≥ 1 또는 0 근처) | ISO 6336-1 |
| 외경·길이 초과 | 커버·플랜지·벽 두께를 가공 최소(2 mm)까지 → 그래도 넘으면 후보 탈락 | Q14 |
| 유막비 λ < 1 | **판정 정보로만 표시** (피팅·굽힘 판정과 별개, 엔진 기존 원칙). 윤활제 사양은 사용자·제조 단계에서 결정 | 오늘 시안에서 점도 등급을 임의로 올린 문제 반영 |

## 7. 산출물

**기어 제원표 (단별 · 썬 / 유성 / 링):** 잇수 · 모듈 · 압력각 · 비틀림각 · 전위 · 기준원 · 이끝원 · 이뿌리원 · 치폭 · 정밀도 · 재료·열처리 · SH · SF (정격 / 피크) · 작동 중심거리 · 감속비.

**부품 BOM:** 부품명 · 수량 · 주요 치수 (외경·내경·폭 또는 형번) · 재질 · 열처리 · 추정 질량 · 판정 (안전율 또는 수명) · 결합 방식.

**요약:** 요구 정격(§2-1)과 예측 정격, 안전율(SH ≥ 1.0 · SF ≥ 1.4), 지배 부품, 가정 목록, 재검토 대상(소형 저하중).

출력 형식: 화면 표 + 엑셀 내보내기 (의뢰서와 같은 파일의 결과 시트) + DB 케이스 JSON.

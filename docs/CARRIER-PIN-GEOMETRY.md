# 캐리어·유성 핀 형상 규칙

10단계에서 지정한 치수는 하나의 캐리어 모델로 해석한 뒤 3D 조립, BOM, 핀 보 계산에 전달한다. 아래 좌표는 각 단의 유성기어 입력측 치면을 0으로 하고 감속기 출력 방향을 +Z로 한다.

| 항목 | 명목 규칙 |
| --- | --- |
| 핀 배치 | 외접 치합의 작용 중심거리 a를 사용한다. PCD는 2a이고, 유성 수만큼 등각으로 배치한다. |
| 편단지지 | 원통 보어를 가진 지지판 한 장. 1단은 입력측, 2단은 출력측에서 지지한다. 지지판부터 기어 하중 구간까지의 간격은 기본 0 mm다. |
| 양단지지 | 유성 치폭을 중심으로 두 지지판을 대칭 배치한다. 중앙 홈 폭은 기본 치폭 + 0.6 mm이고, 방사 방향으로 열린 유성 안착부 폭은 유성 이끝원경 + 4 mm다. |
| 보스 | 1단 입력측, 2단 출력측. 초기 가정은 높이 4 mm이며, 외경은 핀 홀과 겹치지 않도록 자동 결정한다. 높이 0은 보스 생략이다. |
| 관통 | 양단은 두 판과 사이 공간을 지난다. 편단은 지지판을 관통한다. 보스가 홀 단면을 덮으면 해당 두께도 관통한다. |
| 막힌 홀 | 원통 깊이와 118° 드릴 끝으로 구성한다. 원통 구간에만 핀이 놓이며, 양단지지에서는 맞은편 판에 원통 구간이 닿아야 한다. |
| 핀 길이 | 양단은 가공 원통 구간 전체. 편단은 원통 삽입 길이와 유성기어를 지나는 돌출부의 합. 지지 스팬과 별도 값이다. |
| 핀 보 해석 | 양단은 각 판의 원통 체결 구간 중심을 반력점으로 사용한다. 편단은 기어에 가까운 판 면부터 하중 구간까지의 외팔보다. 판 내 평균 면압은 판 반력과 원통 체결 길이로 계산한다. |

중앙 연결부의 3D는 방사 슬롯을 가공한 링의 명목 형상이다. 연결부 강성은 10단계의 등가 단면과 해당 홈 폭을 사용하는 보 근사다. 끼워맞춤 공차, 압입잔류응력, 판 탄성은 설계자가 별도로 확인한다.

확인 명령은 `node carrier_geometry_test.js`, `node compat_test.js`다. 기존 Ø10 양단지지 비교점은 기준 기어 한계 10.877603 N·m와 정적 한계 41.211661 N·m를 재현한다.
